# Ordering flow

1. Browse/filter the sample catalog.
2. Build a box; adjust/remove quantities (12 each; server 48 overall).
3. Choose available pickup; preview dates are examples only.
4. Name/email, optional phone/note; no payment data.
5. Review and correct details.
6. Live mode: consent and send; pending state prevents double clicks.
7. Server validates/fingerprints, locks, checks retries/capacity, calculates trusted prices and writes a private Sheet row.
8. Only a readable matching receipt permits success. Timeout/CORS failure is **unconfirmed**; unchanged retries keep their identity.
9. Bakery separately confirms arrangements and price.

Preview cannot submit or show fake confirmation. Opening confirmation without a receipt shows a neutral explanation.
