# Soft Strange Bakery repository memory

- Purpose: Soft Strange Bakery’s customer-facing website for its weekly Saturday bake sale, currently in a pre-order launch state.
- Architecture: Next.js static export under `/AngelsBakery`; domain and services own rules, view-models own state, and views own presentation.
- Conventions: preserve the base path, image provenance and reduced-motion support. Keep real ordering disabled until business approval and live receipt evidence are in place.
- Dependency convention: pin `next` and `eslint-config-next` to the same exact version. Recheck the audit before release; as of 2026-10-12, production dependencies audit clean while the dev-only `braces` chain has no published patched release.
- Visual direction: adapt Soft Strange Studio’s handmade paper, sage frame, soft color accents, hand lettering, and lightly tilted scrapbook cards to the bakery’s pastry imagery. Keep it warm, personal, and almost blog-like, with a comfortable first screen at ordinary window sizes. Use a centered taped note for bake-sale facts, a subtle stagger on wide-desktop featured cards, and paper backing for the existing story copy. Make restrained styling changes and preserve existing wording unless directed otherwise. Keep the pastry carousel’s upper edge flat and masthead centered; retain a discreet Saturday box link in the masthead so the existing order route remains reachable. Keep factual site copy and concept-image labels grounded in approved information.
- Fit behavior: short desktop windows (≤850px tall) use a compact hero/carousel; `/menu/` gets an extra reduction (128px hero, 56px carousel at 1280×720) so products appear sooner. Short phones (≤700px tall) use a 220px hero and 98px carousel; regular 390×844 phones retain 304px/118px sizing. On narrow phones, avoid an orphaned featured-heading word, use a shrinkable single-column product grid across home/menu/detail cards, stack price labels at ≤360px, and keep carousel controls clear. Verify all customer routes at small widths after shared card or hero styling changes.
